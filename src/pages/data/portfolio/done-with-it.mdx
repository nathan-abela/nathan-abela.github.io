Selling unwanted items usually means friction: accounts, listings, and endless back-and-forth. Done With It is a React Native marketplace app built with Expo that strips the process down to the essentials - photograph an item, list it, and get notified when someone is interested.

Across its 10 screens the app covers user authentication, form validation, offline support, and push notifications, backed by a REST API.
