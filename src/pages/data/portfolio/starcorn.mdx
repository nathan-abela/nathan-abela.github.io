GitHub stars pile up into an unmanageable list - hundreds of repositories with no way to group them, search them, or get them back out. Starcorn organises any user's stars without authentication: repositories are automatically sorted into 20+ categories, re-arrangeable with drag and drop, and exportable to Markdown, JSON, or CSV.

Everything runs client-side - no OAuth, no backend, no data leaving the browser - works instantly for any GitHub username.
